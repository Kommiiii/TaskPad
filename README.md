# TaskPad

A clean, distraction-free task management application designed with a classic typewriter aesthetic. TaskPad allows you to organize your daily activities in a familiar, tactile interface while utilizing modern web features like persistent storage and theme toggling.

### Try the Webpage
You can access the live version of the project here:
[https://kommiiii.github.io/TaskPad/](https://kommiiii.github.io/TaskPad/)

---

### Features
* **Typewriter Aesthetic:** Built with a strict Courier New font family, ruled lines, and a classic notepad design.
* **Persistence:** Uses localStorage to save your tasks, so your to-do list stays exactly where you left it, even after closing the browser.
* **Theme Toggle:** Easily switch between Light and Dark modes to match your environment.
* **Mobile-First:** Fully responsive design that feels like a physical notebook on phone screens.
* **Drag & Drop:** Reorder your tasks naturally to prioritize what is important.
* **Pagination:** Organize your tasks across multiple pages.

### Built With
* **HTML5** - Structure and layout.
* **CSS3** - Styling, Flexbox/Grid for layout, and custom themes.
* **Vanilla JavaScript** - Logic for task management, drag-and-drop, and data persistence.
